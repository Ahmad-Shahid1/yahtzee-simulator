# Yahtzee Simulator

A two-player Yahtzee simulator built with Java, JavaFX, and FXML. The project combines an interactive dice-game interface with reroll logic, real-time frequency displays, and scoring across 13 categories.

## Features

- Two-player JavaFX interface.
- Reroll logic for 10 dynamic dice values.
- Real-time dice-frequency displays.
- A 13-category scoring pipeline with instant calculations and rule enforcement.

## Technologies

- Java
- JavaFX
- FXML
